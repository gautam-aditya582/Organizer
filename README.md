I designed and implemented a **File Organizer tool in Python** to automate file management and reporting. This project allowed me to apply my programming skills to solve a real-world problem of cluttered directories and repetitive manual sorting.  

 🔹 Key Contributions  
- Built a **modular Python class (`FileOrganizer`)** to handle file categorization and movement.  
- Defined **file type mappings** for images, documents, videos, audio, archives, code, and spreadsheets.  
- Automated the process of **moving files into structured destination folders** using `shutil` and `pathlib`.  
- Developed a **report generation system** that provides:  
  - File counts by category  
  - Total files moved  
  - Number of folders created  
- Implemented **duplicate handling logic** to skip files that already exist in the destination.  
- Created a **command-line interface (CLI)** for user-friendly interaction.  

 🛠️ Skills Showcased  
- Python (OOP, file handling, automation)  
- Libraries: `os`, `shutil`, `pathlib`  
- Problem-solving and workflow optimization  
- Clean code practices and modular design  

 🚀 Impact  
- Reduced manual effort by automating repetitive file organization tasks.  
- Improved productivity by keeping directories clean and structured.  
- Delivered a transparent **reporting system** for tracking progress and results.
